# Химия руками

Курс химии для взрослых с нуля. Каждый урок начинается с практической задачи из жизни: кухня, уборка, сад, авто, аптечка, ремонт и другие сферы. Урок проходит пять шагов:

1. **Задача** — бытовая ситуация.
2. **Гипотеза** — ученик угадывает ответ до теории.
3. **Опыт** — виртуальная лаборатория: стакан с пузырями, пеной и термометром (макро) и «лупа», где видно, как атомы меняют партнёров (микро).
4. **Расчёт** — пошаговая задача, числа каждый раз новые.
5. **Закрепление** — вопросы уходят в «Коллекцию кристаллов» (интервальное повторение, как в курсе про фараонов).

Сейчас готова пробная миссия «Зачем гасить соду уксусом».

## Запуск

Сайт статический, без сборки, но на ES-модулях. Поэтому его нужно открывать через локальный сервер, а не двойным щелчком по файлу:

```
python -m http.server 8000
```

Потом откройте http://localhost:8000/.

Для проверки повторения можно сдвинуть «сегодня»: `garden.html?shift=3`.

## Проверка химии

```
node tools/check.mjs
```

Скрипт проверяет, что каждое уравнение уравнено, что атомы в «лупе» совпадают с уравнением и что карточки ссылаются на существующие уроки.

## Устройство

- `data/` — всё содержимое курса:
  - `course.js` — модули, уроки и шаги;
  - `reactions.js` — реакции: уравнение, эффекты в стакане, сценарий для «лупы»;
  - `substances.js`, `elements.js`, `spheres.js`, `cards.js`.
- `js/engine/` — переиспользуемые тренажёры:
  - `lab.js` (полка и логика реакций), `lab-macro.js` (стакан), `lab-micro.js` («лупа»);
  - `calc.js` (расчётный стол), `equation.js` и `formula.js` (уравнения и формулы).
- `js/core/` — интервальное повторение (`srs.js`), прогресс и доступ к урокам (`progress.js`), помощники.
- `js/pages/` — страницы: карта курса, плеер урока, коллекция.

Новый опыт — это новая запись в `data/reactions.js`, а не новый код.
